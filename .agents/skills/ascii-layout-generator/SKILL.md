# ASCII 字符画布局生成器（AsciiLayoutGenerator）

## 目标

将页面规格说明（PAGE_SPECS 或结构化需求）转化为 ASCII 字符画布局图，在进入原型设计或编码前，用最低成本确认页面结构和模块关系。

## 何时使用

- 页面需求刚确认，需要快速对齐"页面长什么样"
- 团队评审页面结构，不想画原型图
- AI 生成代码之前确认布局骨架
- 验证 DesignGenerator 输出的组件组织是否合理
- 多个方案对比时，快速产出不同布局变体

## 输入

支持以下任一格式：

| 来源 | 格式 | 说明 |
|------|------|------|
| RequirementAnalyzer 输出 | JSON (`pages[].modules[]`) | 最简输入，只有模块名 |
| DesignGenerator 输出 | Markdown (`PAGE_SPECS.md`) | 含组件建议，可标注组件类型 |
| 自定义 JSON | 见下方示例 | 手动指定的模块列表 |
| 自然语言 | 文本描述 | "一个后台管理页面，顶部搜索栏，中间表格，底部分页" |

### 自定义 JSON 示例

```json
{
  "page": "用户管理",
  "modules": [
    { "name": "搜索区域" },
    { "name": "用户列表" },
    { "name": "分页区域" }
  ]
}
```

## 输出格式

默认输出 Markdown，包含 ASCII 布局图 + 布局说明。

### 输出模板

````markdown
# 页面布局：{页面名称}

```
+------------------------------------------------+
| Header                                         |
+------------------------------------------------+

+------------------------------------------------+
| 搜索区域                                        |
+------------------------------------------------+

+------------------------------------------------+
| 用户列表                                        |
|                                                |
|                                                |
+------------------------------------------------+

+------------------------------------------------+
| 分页区域                                        |
+------------------------------------------------+
```

## 布局说明

- 搜索区域位于列表上方
- 编辑功能通过弹窗实现（弹窗不占页面空间）
- 分页位于页面底部
- 空状态时列表区显示占位提示
````

## 布局规则（严格遵循）

| 规则 | 说明 |
|------|------|
| 1. 从上到下 | 页面按视觉阅读顺序纵向排列 |
| 2. Header 优先 | 如有顶栏/导航，始终置于最顶部 |
| 3. 业务顺序 | 功能模块按用户操作流程排列（搜索→列表→分页→操作） |
| 4. 表格留空 | 表格类模块增加 2-3 行空白占位，示意数据区域 |
| 5. 表单留位 | 表单类模块增加字段占位行（如 `[姓名____] [邮箱____]`） |
| 6. 按钮标注 | 操作区显示按钮文字，如 `[ 搜索 ] [ 重置 ]` |
| 7. 弹窗不绘 | 弹窗、抽屉、下拉菜单不在主布局中绘制，在"布局说明"中注明 |

## 模块类型识别

从需求/设计中识别以下模块类型，决定占位方式：

| 类型 | 关键词 | 占位方式 |
|------|--------|----------|
| 表格 | 列表、表格、table | 表头行 + 2~3 行数据占位 |
| 表单 | 输入、表单、编辑 | 2~3 个字段占位 + 提交按钮 |
| 搜索 | 搜索、筛选、查询 | 输入框 + 下拉 + 按钮 |
| 统计 | 统计、指标、卡片、chart | 卡片排列 `[指标A] [指标B] [指标C]` |
| 操作栏 | 新增、批量、导出 | 按钮排列 `[新增] [批量删除] [导出]` |
| 分页 | 分页、翻页 | 单行简化 `<< 1 2 3 >>` |
| 树/菜单 | 树、菜单、导航 | 侧栏缩进结构 |

## 工作步骤

1. **解析输入**：提取页面名称和所有模块
2. **识别模块类型**：按关键词匹配上表，确定占位方式
3. **推断布局顺序**：Header → 操作栏 → 搜索/筛选 → 主体内容（表格/表单/统计）→ 分页
4. **绘制 ASCII 图**：统一宽度 52 字符，纵向排列，模块间加空行
5. **标注交互区域**：将弹窗、右键菜单等非页面内元素写入"布局说明"
6. **输出布局说明**：用简短语句描述结构关系和交互方式

## 多方案对比模式

若用户输入包含 `对比` 或 `多方案` 关键词，生成 2~3 种布局变体：

````markdown
# 布局方案对比：用户管理

## 方案 A：搜索在上
```
+------------------------------------------------+
| 搜索区域                                        |
+------------------------------------------------+
| 用户列表                                        |
+------------------------------------------------+
| 分页                                            |
+------------------------------------------------+
```
- 适合：搜索条件少、列表为主

## 方案 B：搜索在侧
```
+--------------------+---------------------------+
| 搜索筛选           | 用户列表                   |
| [姓名____]         |                           |
| [状态 v]           |                           |
|                    |                           |
+--------------------+---------------------------+
| 分页                                            |
+------------------------------------------------+
```
- 适合：筛选条件多、宽屏显示器
````

## 示例

### 输入（来自 DesignGenerator）

```
页面: 用户管理
模块:
- 搜索区域: 姓名输入框、状态下拉、搜索按钮、重置按钮
- 用户列表: 表格（姓名、邮箱、状态、注册时间、操作）
- 分页
弹窗: EditUserModal（编辑用户信息）
```

### 输出

````markdown
# 页面布局：用户管理

```
+------------------------------------------------+
| Header: Logo + 导航 + 用户头像                   |
+------------------------------------------------+

+------------------------------------------------+
| 操作栏: [ 新增用户 ] [ 批量导入 ] [ 导出 ]        |
+------------------------------------------------+

+------------------------------------------------+
| 搜索: [姓名____] [状态 v] [ 搜索 ] [ 重置 ]       |
+------------------------------------------------+

+------------------------------------------------+
| 用户列表                                        |
|------------------------------------------------|
| 姓名   | 邮箱        | 状态  | 注册时间 | 操作  |
|--------|------------|------|---------|------|
| ...    | ...        | ...  | ...     | 编辑  |
| ...    | ...        | ...  | ...     | 编辑  |
| ...    | ...        | ...  | ...     | 编辑  |
+------------------------------------------------+

+------------------------------------------------+
| << 1  2  3 ... 10 >>  共 200 条                 |
+------------------------------------------------+
```

## 布局说明

- 操作栏位于搜索上方，便于快速新增
- 搜索支持姓名模糊匹配 + 状态下拉筛选
- 编辑操作通过弹窗 EditUserModal 实现（不占页面空间）
- 表格操作列含"编辑"链接按钮
- 分页显示页码和总条数
````

## 注意事项

- 仅关注布局结构，不涉及颜色、字体、间距等视觉属性
- 不猜测需求中不存在的模块；不确定的标注 `[待确认]`
- ASCII 图宽度固定 52 字符，保证在终端和 Markdown 中可读
- 表格列数 ≤ 6，超出时用省略号 `...` 代替
- 弹窗/抽屉/右键菜单在文字说明中描述，不占布局图空间
- 与 `requirement-analyzer` → `design-generator` → `business-logic-checker` 链式兼容
