## 问题列表

### 🔴 问题1：P2 布局未同步优化（旧格式残留）

- **维度**：信息架构 / 视觉结构
- **现象**：P2 导入页仍使用旧的带侧边栏布局格式，与 P1/P3~P6 的新格式不一致
- **影响**：侧边栏占用 8 字符宽，主内容区被挤压；全局布局中已声明侧边栏由 AppLayout 统一管理，页面级别不应重复绘制。P2 实际可用宽度仅 38 字符，信息过于拥挤
- **建议**：将 P2 改为与其他页面一致的无侧边栏格式（52 宽全利用）
- **扣分**：-6（信息架构 -3 / 视觉结构 -3）

### 🔴 问题2：P4 缺少返回导航路径

- **维度**：信息架构 / 用户体验
- **现象**：P4 任务详情页是深层页面，但布局图中无面包屑或"返回任务列表"按钮
- **影响**：用户完成任务查看后无法快速返回列表，需依赖浏览器后退或侧边栏导航
- **建议**：在标题栏增加面包屑 `← 返回任务列表` 或 `任务列表 > 斗破苍穹分析`
- **扣分**：-4（信息架构 -2 / 用户体验 -2）

### 🟡 问题3：P2 章节识别区域信息密度过高

- **维度**：视觉结构 / 用户体验
- **现象**：Step 2 单区域包含：策略状态、命中率、内置规则、自定义正则输入、章节预览按钮共 5 类元素
- **影响**：用户注意力分散，自定义正则输入容易被忽略
- **建议**：将"内置规则"默认折叠，仅显示当前命中率 + 策略 + 自定义正则输入 + 预览按钮
- **扣分**：-3（视觉结构 -2 / 用户体验 -1）

### 🟡 问题4：P3 任务列表缺少"创建任务"入口

- **维度**：用户体验
- **现象**：P3 页面布局只有筛选 + 表格 + 分页，没有直接创建新任务的入口
- **影响**：用户必须回到首页或导入页才能创建新任务，操作路径变长
- **建议**：在筛选栏上方或旁边增加 `[ + 新建分析任务 ]` 按钮
- **扣分**：-3（用户体验 -3）

### 🟡 问题5：P5 工具栏存在"按钮风暴"风险

- **维度**：视觉结构
- **现象**：P5 工具栏 5 个平级按钮：保存 | 导出▼ | 校验 | 润色▼ | 历史
- **影响**：保存是最高频操作，与低频的导出/润色/历史平级排列，主次不分
- **建议**：保存保持主按钮突出样式，导出▼ 和 润色▼ 保持下拉，校验和历史收入"更多 ▼"
- **扣分**：-2（视觉结构 -2）

### 🟢 建议1：表格缺少空状态占位

- **维度**：用户体验
- **现象**：P1（最近任务）和 P3（任务列表）的布局图中只有数据行，未定义空状态占位
- **影响**：无数据时用户看到空白区域，不确定是加载失败还是确实无数据
- **建议**：P1 增加 `暂无任务，[去导入小说 →]`；P3 增加 `暂无任务，[创建第一个 →]`

### 🟢 建议2：P5 缺少视图切换按钮

- **维度**：用户体验
- **现象**：P5 布局说明提到支持三种视图（分屏/仅编辑/仅预览），但布局图中无切换按钮
- **建议**：在编辑器顶部增加视图切换 `[ ◐ 分屏 | 📝 仅编辑 | 📖 仅预览 ]`

### 🟢 建议3：P6 Schema 树建议增加搜索

- **维度**：用户体验
- **现象**：Schema 树结构深（3~4 层），字段多时查找困难
- **建议**：在 Schema 树上方增加字段搜索框 `🔍 [搜索字段名...]`

### 🟢 建议4：P0 注册表单字段数控制

- **维度**：用户体验
- **现象**：注册表单 3 个字段（用户名/账号/密码），重置密码 2 个字段（用户名/新密码）——均在合理范围
- **建议**：无需调整，但建议在注册表单增加"确认密码"字段（当前缺失，可能导致用户输错密码）
