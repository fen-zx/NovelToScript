# DESIGN — AI小说转剧本工具

## 系统架构

```
┌──────────────────────────────────────────────────┐
│                   前端 (Vue 3)                     │
│    Element Plus | Pinia | Monaco Editor           │
│         SSE 流式接收 AI 进度                       │
│  ┌──────────────────────────────────────────┐    │
│  │         前端离线缓存层                     │    │
│  │  localStorage: 配置 / 任务状态             │    │
│  │  IndexedDB: 小说原文 / YAML草稿 / 生成结果  │    │
│  └──────────────────────────────────────────┘    │
└──────────────────────┬───────────────────────────┘
                       │ HTTP + SSE
┌──────────────────────▼───────────────────────────┐
│                 后端 (Express)                     │
│    LangChain Agent 编排 | BullMQ 任务队列          │
│    并发限制: 运行1 / 排队3                         │
│    章节识别: 规则→目录→AI→切片→人工                │
│    文本分片: 章节→段落→语义 (5000~8000字/片)       │
└──┬──────────┬──────────┬─────────────────────────┘
   │          │          │
   ▼          ▼          ▼
┌──────┐ ┌──────┐ ┌──────────┐
│SQLite│ │Redis │ │  MinIO   │
│(主库)│ │(缓存)│ │(文件存储) │
└──────┘ └──────┘ └──────┬───┘
                         │
                    ┌─────▼──────┐
                    │ 存储生命周期 │
                    │ 原文+中间:30d │
                    │ 最终剧本:永久 │
                    │ 单用户:500MB │
                    └────────────┘
```

## 技术栈

### 前端

| 类别         | 技术                     | 用途               |
| ------------ | ------------------------ | ------------------ |
| 框架         | Vue 3                    | 主框架             |
| 语言         | TypeScript               | 类型安全           |
| UI库         | Element Plus             | 组件库             |
| 状态管理     | Pinia                    | 全局状态           |
| 路由         | Vue Router               | 页面路由           |
| 网络请求     | Axios                    | HTTP 客户端        |
| YAML编辑器   | Monaco Editor            | 剧本编辑           |
| Markdown预览 | markdown-it              | 预览渲染           |
| 流式输出     | EventSource / SSE        | AI 进度展示        |
| 离线缓存     | localStorage + IndexedDB | 配置/草稿/生成结果 |

### 后端

| 类别      | 技术         | 用途                |
| --------- | ------------ | ------------------- |
| Runtime   | Node.js      | 运行环境            |
| Web框架   | Express      | HTTP 服务           |
| Agent框架 | LangChain    | AI Agent 编排       |
| LLM       | DeepSeek API | 大语言模型          |
| 数据库    | SQLite       | 主数据存储          |
| 缓存      | Redis        | 缓存 & 队列持久化   |
| 队列      | BullMQ       | 异步任务            |
| ORM       | Prisma       | 数据建模            |
| 文件存储  | MinIO        | 小说原文 & 结果存储 |
| 配置管理  | dotenv       | 环境变量            |

### AI Agent 流水线

```
Novel Analysis Agent       → 分析小说结构（章节/主题/风格）
        ↓
Character Extraction Agent → 提取人物信息（角色/关系/性格）
        ↓
Plot Extraction Agent      → 剧情拆解：事件→冲突→转折→高潮→结局
        ↓
Scene Planning Agent       → 场景规划：时间→地点→参与者→场景目标
        ↓
Script Generation Agent    → 生成剧本内容（YAML 格式）
        ↓
YAML Validation Agent      → 校验 YAML 格式 & Schema 合规
        ↓
Script Polish Agent        → 润色优化（7 种风格可选）
```

### Agent 职责边界

| Agent           | 核心问题           | 关注维度                     |
| --------------- | ------------------ | ---------------------------- |
| Plot Extraction | 故事发生了什么？   | 事件、冲突、转折、高潮、结局 |
| Scene Planning  | 剧情如何拆成场景？ | 时间、地点、参与者、场景目标 |

### 润色风格

`原著还原` | `影视剧风格` | `短剧风格` | `动漫风格` | `电影风格` | `电视剧风格` | `舞台剧风格`
