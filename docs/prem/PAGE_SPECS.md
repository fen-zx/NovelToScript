## P0 — 登录注册页

**描述**: 用户认证入口，支持登录、注册、密码重置

**路由**: `/auth`

**模块**:

- M1: 登录表单（账号 + 密码输入，登录按钮，切换注册/重置密码链接）
- M2: 注册表单（用户名 + 账号 + 密码输入，账号唯一性校验，注册按钮）
- M3: 密码重置表单（用户名输入验证身份，新密码设置）

**规则**:

- 注册：用户名 + 账号 + 密码，账号不可重复
- 密码重置：需输入用户名验证身份后方可重置

## P1 — 项目首页

**描述**: 展示项目概况，提供各功能入口

**模块**:

- M1: 导航栏（Logo | 首页 | 导入 | 任务列表 | Schema文档）
- M2: 项目简介卡片
- M3: 快速操作入口（导入小说 / 查看任务 / 新建剧本）
- M4: 最近任务列表

---

## P2 — 小说导入页

**描述**: 上传小说文本或文件，配置导入参数

**模块**:

- M1: 文本输入区（粘贴或拖拽上传 .txt / .docx / .md，单文件 ≤20MB）
- M2: 章节识别设置（内置规则 + 自定义正则输入，实时显示命中率，识别结果预览+手动调整）
- M3: 导入参数配置（书名、作者等元数据）
- M4: 提交按钮 → 创建分析任务

---

## P3 — 分析任务页

**描述**: 查看所有分析任务及状态

**模块**:

- M1: 任务列表表格（任务名 | 状态 | 进度 | 创建时间 | 操作）
- M2: 状态筛选（全部 | 排队中 | 进行中 | 已完成 | 失败）
- M3: 删除/重试操作

---

## P4 — 任务详情页

**描述**: 查看单个 AI 分析任务的实时进度和中间结果

**模块**:

- M1: 任务基本信息
- M2: Agent 流水线进度条（7 个阶段，SSE 实时更新）
- M3: 每阶段中间结果展示
- M4: 完成后跳转剧本编辑页按钮

---

## P5 — 剧本编辑页

**描述**: Monaco Editor 编辑生成的 YAML 剧本，实时预览

**模块**:

- M1: Monaco Editor（YAML 编辑，语法高亮 + 校验）
- M2: Markdown 预览面板（渲染剧本为可读格式）
- M3: 工具栏（保存 | 导出 yaml/json/md/pdf/txt | 校验 | 润色(7种风格可选)）
- M4: Schema 校验状态指示
- M5: 版本历史面板（版本列表、预览、回滚）
- M6: 离线缓存状态指示（自动保存状态 / 草稿恢复提示）

---

## P6 — YAML Schema 文档页

**描述**: 展示剧本 YAML Schema 定义及设计原因

**模块**:

- M1: Schema 结构可视化
- M2: 字段说明表格
- M3: 设计原因说明
- M4: 示例剧本展示
